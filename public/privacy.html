Memory Lane

Privacy

Memory Lane asks for a birth year, up to three artist names, and an optional first name. It does not ask about health, diagnosis, or location, and it has no accounts.

A session is stored for 30 days so you can come back to it and print the summary. It holds the inputs, the songs and shows chosen, and the reactions you tapped. Use "Delete this session" to remove it at any time.

Artist and song lookups go to Qloo. Audio previews come from Apple's iTunes Search API. Cached lookups stay on the server and are not shared.

Memory Lane is an activity planner for family caregivers. It is not therapy and gives no medical advice.
