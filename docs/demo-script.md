# 3-minute demo script

- 0:00 Opening scene: the group chat with no decision, one stat from the evaluation or Qloo docs.
- 0:20 Thesis in one line, with `/encore` already typed with no place named.
- 0:40 Tap "Use my location", approve in the browser, see the shortlist land in Discord.
- 1:20 Vote, then Replan ("quieter, under $35") and show the list change.
- 2:00 Privacy line: 25 messages read once, raw text discarded. Show the unavailable state.
- 2:20 Architecture: Qloo Search, Tags, Insights; code enforces limits. Evaluation table with the miss.
- 2:45 Close on the final voted place.

Fallback with no Discord token: record `/demo.html` and `/locate.html` (scripts/record-demo.mjs).
